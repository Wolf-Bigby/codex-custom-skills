# Response Letter Skill

Use this reference when drafting editor replies, reviewer responses, rebuttal letters, or point-by-point responses for remote sensing environmental science manuscripts.

## Standard Response Logic

Each response should follow five steps:

1. Acknowledge the comment politely.
2. Identify the core issue.
3. State the manuscript revision or analysis performed.
4. Provide concrete evidence: section, figure, table, citation, equation, experiment, or revised sentence.
5. Explain how the revision addresses the concern.

## Tone

Use a constructive, respectful, evidence-based tone. Avoid defensive wording. Do not over-apologize unless the issue is a clear error. Use `we respectfully acknowledge` when partly disagreeing. Use `we agree` only when the manuscript was revised accordingly.

## Response Types

### Editor overview

```text
We sincerely thank the editor for the careful handling of our manuscript and for the constructive comments. We have revised the manuscript thoroughly to address the concerns raised by the reviewers. The major revisions include [revision 1], [revision 2], and [revision 3]. Detailed point-by-point responses are provided below.
```

### Literature comment

```text
We thank the reviewer for this helpful suggestion. We have added recent studies on [topic] in Section [X] to better position our work within the existing literature. These references support the discussion of [specific point] and clarify how our study differs from previous approaches.
```

### Method rationale comment

```text
We respectfully acknowledge the reviewer’s concern regarding [method issue]. In the revised manuscript, we clarified the rationale for [method choice] in Section [X]. Specifically, [technical explanation]. We also added [ablation/comparison/sensitivity analysis] in [Fig./Table X], which shows [key result].
```

### Validation comment

```text
To address this concern, we added an additional validation experiment using [data/reference/protocol]. The results are reported in [Fig./Table/Section X]. As shown, [quantitative result], indicating that [bounded interpretation].
```

### Dataset or availability comment

```text
We agree that data availability is important for reproducibility and reuse. We have revised Section [X] to provide [access link/version/file format/variable description]. We also added information on [uncertainty/quality flag/license] to help users interpret the dataset appropriately.
```

### Overclaiming comment

```text
We appreciate this important point. We have softened the statement in Section [X] from [original claim] to [revised claim] to better reflect the evidence available in this study. We also added a limitation noting that [boundary condition].
```

### Partial disagreement

```text
We appreciate the reviewer’s suggestion. While [suggested analysis] would be valuable, it is not fully applicable in the present study because [reason]. To avoid overinterpretation, we have clarified this limitation in Section [X] and identified it as a direction for future work.
```

### Minor correction

```text
We thank the reviewer for the careful reading. We have corrected this issue in [location]. We also checked related terms, figure labels, and cross-references for consistency throughout the manuscript.
```

## Evidence Checklist

Before finalizing, each response should include at least one evidence item:

- Section number.
- Figure or table number.
- Revised sentence.
- Added citation.
- Added experiment.
- Quantitative result.
- Data availability statement.
- Limitation statement.

If evidence is missing, write a fillable response and flag the missing item instead of inventing it.
