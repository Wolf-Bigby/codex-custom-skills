# Source Corpus

This skill is derived from the local White Group paper folder and the existing v1 materials:

- `Remote_Sensing_Writing_Skill.md`: v1 general remote sensing environmental science writing guide.
- `deep-research-report.md`: consolidated style analysis and section-level guidance.
- Representative PDFs in the same folder: method papers, dataset papers, synthesis papers, air-quality gap filling, methane retrieval, and PM2.5 mapping.

## Representative Papers

1. **Global synthesis of two decades of research on improving PM2.5 estimation models from remote sensing and data science perspectives**
   - Type: review/synthesis.
   - Style value: builds broad motivation, classifies method families, compares limitations, and identifies future directions.

2. **SCAGAT: A scene-aware ensemble graph attention network for global PM2.5 pollution mapping via land-atmosphere interactions**
   - Type: method innovation and global PM2.5 mapping.
   - Style value: model-name title, scene mechanism, graph attention, validation, ablation, and land-atmosphere interpretation.

3. **100 m PM2.5 mapping from SDGSAT-1 TOA reflectance: Model development and evaluation**
   - Type: high-resolution mapping method and evaluation.
   - Style value: clear scale, sensor, target variable, model development, independent evaluation, and urban heterogeneity.

4. **Developing unbiased estimation of atmospheric methane via machine learning and multiobjective programming based on TROPOMI and GOSAT data**
   - Type: methane retrieval / bias correction method.
   - Style value: multisensor integration, bias control, multiobjective optimization, retrieval uncertainty, and cross-product validation.

5. **SSRMF: A sparse spectral reconstruction enhanced matched filter for improving point-source methane emission detection in complex terrain**
   - Type: method innovation for point-source methane detection.
   - Style value: acronym title, complex-terrain challenge, spectral reconstruction, matched filtering, detection performance, and case validation.
   - Note: two SSRMF PDFs are present locally; treat them as one paper.

6. **Advancing the prediction accuracy of satellite-based PM2.5 concentration mapping: A perspective of data mining through in situ PM2.5 measurements**
   - Type: applied PM2.5 mapping and data mining.
   - Style value: station-aware modeling, in situ measurement mining, satellite-based estimation, and practical accuracy improvement.

7. **DCCEOF air-quality gap filling paper in Atmospheric Measurement Techniques**
   - Type: measurement/data gap filling method.
   - Style value: method practicality, constrained reconstruction, validation under missing-data conditions, and methodological transparency.

8. **LGHAP 2022: Long-term Gap-free High-resolution Air Pollutant concentration dataset**
   - Type: ESSD dataset paper.
   - Style value: dataset naming, product generation, long-term gap-free coverage, validation, data access, and reuse potential.

9. **LGHAP 2024 enhancement**
   - Type: ESSD dataset update and extension.
   - Style value: versioned product evolution, quality improvement, coverage extension, uncertainty documentation, and community utility.

## Corpus-Level Style Pattern

The corpus follows a stable sequence: scientific need -> data or remote-sensing opportunity -> limitation of current methods/products -> study response -> validation evidence -> spatial/temporal interpretation -> bounded implications. Method papers place novelty in framework design and validation. Dataset papers place novelty in data lineage, quality control, uncertainty, and reuse. Application papers balance accuracy, spatial pattern, and environmental interpretation.
